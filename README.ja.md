# nur_ieren Menu Toggler
[English](README.md)

Unityのメニューがかさばるときに、メニュー項目の表示・非表示を切り替えられるエディタ拡張です。

## 動作環境

- Unity 2022.3.22f1（本ツールの想定バージョン）

## 導入方法

`Assets/nur_ieren/MenuToggler/` フォルダをプロジェクトにコピーしてください。

```
Assets/
└─ nur_ieren/
   └─ MenuToggler/
      ├─ nur_ieren.MenuToggler.asmdef   （Editor専用アセンブリ）
      ├─ MenuToggleCore.cs
      ├─ MenuToggleSettings.cs
      └─ MenuToggleWindow.cs
```

`Assets/Editor/` に置かなくても、`Assets/nur_ieren/` 配下で動作します。Editor専用のasmdefにより、プレイヤービルドには含まれません。

## 使い方

1. メニューバーの **`nur_ieren > Menu Toggler`** を開きます。
2. 最上位メニュー（例: `Tools`）のチェックを外すとグループごと非表示になります。展開して個別の項目だけ外すこともできます。
3. 検索欄で絞り込めます。スクリプトを追加したあとは **再読込** でメニューを再取得します。
4. **適用** を押します。
   - 新しく非表示にした項目はすぐに消えます。
   - 表示に戻した項目がある場合は、メニューを再構築するためスクリプトが再読込されます。
5. **全て表示** で設定をすべてリセットできます。

`nur_ieren` メニュー自身は一覧に出ず、隠すこともできません。

## 仕組み

Unityにはメニュー項目を隠す公式APIがないため、内部メソッド `Menu.RemoveMenuItem` をリフレクションで呼んでいます。

- 取り除かれるのは、現在メモリ上にあるメニューだけです。アセットのインポートなどでドメインリロードが走るたびにUnityがメニューを作り直すので、隠した項目は一度復活します。
- これに対応するため、アセンブリのリロード後、プロジェクトの変更時、編集モードへ戻ったときに設定を再適用します。きっかけのあとは10秒間、1秒おきに再適用を続け、段階的に作り直されるメニューも拾います。
- 設定は `Assets/` の外にある `UserSettings/nur_ieren/MenuToggler.asset` に保存されるため、再インポートは発生しません。このフォルダはバージョン管理の対象外にするのが一般的です。

## 制限事項

- Unity内部のメソッドに依存しているため、他のバージョンでは動かなくなる可能性があります。
- 一覧に出るのは `[MenuItem]` で登録されたメニューだけです。`File > New Scene` のようなエンジン内部の項目は対象外です。
- リロードやインポートの直後は、隠した項目が最大1秒ほど一時的に再表示されることがあります。
- ショートカット付きの項目（例: `Tools/Foo %g`）は、ショートカット表記を除いたパスで表示されます。すべての項目で消えることを確認できているわけではありません。
